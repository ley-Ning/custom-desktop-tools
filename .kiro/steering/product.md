# Product Overview

**My uTools** is a macOS desktop application launcher inspired by uTools, built with modern web technologies and native Rust backend.

## Core Features

- **Global Shortcut**: Quick access via `Alt+Space` (customizable)
- **Smart Search**: Fuzzy search with initials matching for macOS applications
- **Plugin System**: Built-in plugins for clipboard history, memos, JSON editing, AI chat, translator, calc scratchpad, and more
- **System Tray**: Persistent tray icon with quick access menu
- **Modern UI**: Dark theme with gradient icons, macOS-style design

## Built-in Plugins

1. **Clipboard History** (📋): Auto-records clipboard with search and favorites
2. **Memo Plugin** (📝): Quick notes with tags and pinning
3. **JSON Editor** (📊): Format and edit JSON with CodeMirror
4. **AI Chat** (🤖): Streaming AI conversations with multi-session management, Markdown rendering, and per-conversation system prompts (OpenAI-compatible endpoints)
5. **Translator** (🌐): Multi-engine translation (MyMemory / Google / AI models) with auto language detection
6. **Text Toolkit** (🔐): Base64 / URL / Hex encode-decode and MD5 / SHA-1 / SHA-256 / SHA-512 hashing, fully offline

## Target Platform

macOS only - leverages native macOS APIs for app icon extraction and system integration.
