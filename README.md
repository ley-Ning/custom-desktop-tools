# My uTools

一个类 uTools 的应用启动器，使用 Tauri 2 + Vue 3 + TypeScript 构建，专为 macOS 设计。

## 功能特性

- 🚀 **全局快捷键唤醒**：默认 `Alt+Space`，可自定义
- 🔍 **智能搜索**：模糊搜索 + 首字母缩写匹配
- 🎨 **现代化 UI**：仿 uTools 深色主题设计
- 📱 **应用图标提取**：自动提取 macOS 应用图标
- ⚡ **快速启动**：键盘导航，一键启动应用
- 🎯 **最近使用**：展示最近使用的应用
- 🛍️ **市场精选**：插件市场展示（演示）
- ⚙️ **完整设置界面**：快捷键配置、超级面板、语音交互等
- 🔌 **插件应用市场**：浏览、搜索、安装插件（UI 完成）
- 📋 **剪贴板历史**：自动记录剪贴板历史，支持搜索和收藏
- 📝 **备忘快贴**：快速记录笔记，支持标签和置顶

## 快捷键

- `Alt+Space` - 唤出/隐藏窗口
- `↑` / `↓` - 导航应用列表
- `Enter` - 启动选中的应用
- `Esc` - 清空搜索 / 隐藏窗口

## 开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm tauri dev

# 构建应用
pnpm tauri build
```

## 技术栈

- **前端**：Vue 3 + TypeScript + Vite
- **后端**：Rust + Tauri 2
- **UI**：深色主题 + 渐变图标
- **包管理**：pnpm

## UI 设计

参考 uTools 的设计风格：
- 顶部搜索栏（可拖拽窗口）
- 最近使用区域（横向网格）
- 市场精选区域（4列网格）
- 完整的设置界面（左侧导航 + 右侧内容）
- 深色主题 + 渐变图标
- 流畅的交互动画

### 设置界面功能

- **个人中心**：我的账号、我的数据、团队空间
- **偏好设置**：
  - 搜索框快捷键配置
  - 超级面板开关
  - 鼠标按键弹出设置
  - 长按毫秒响应调节
  - 英文快速翻译
  - 语音交互
  - 自动固定
- **其他功能**：AI 模型、本地启动、快捷方式、所有指令
- **插件应用市场**：点击进入插件市场

### 插件应用市场

- **左侧已安装插件列表**
  - 显示所有已安装的插件
  - 快速访问插件
  - 用户登录入口
  
- **右侧市场内容**
  - 搜索 2987+ 款插件
  - uTools 会员权益横幅
  - 精选插件展示（2列网格）
  - 排行榜（最受欢迎、月度新品、最新上架、最近下载）
  - 一键安装/卸载插件

### 内置插件

#### 剪贴板历史 📋
- **自动监听**：实时监听系统剪贴板变化
- **历史记录**：保存最近 100 条剪贴板内容
- **搜索功能**：快速搜索历史记录
- **收藏功能**：标记常用内容
- **一键复制**：点击即可复制到剪贴板
- **键盘导航**：↑↓ 选择，Enter 复制

#### 备忘快贴 📝
- **快速记录**：快速创建和编辑备忘录
- **标签管理**：为备忘录添加标签分类
- **置顶功能**：重要备忘录置顶显示
- **搜索功能**：搜索标题、内容和标签
- **时间记录**：自动记录创建和更新时间
- **Markdown 支持**：支持 Markdown 格式（计划中）
